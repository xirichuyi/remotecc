# RemoteCC

通过系统 SSH 连接服务器的 Claude Code 客户端：聊天、远端目录、上传附件、文件预览、下载和本地打开。

**macOS 原生客户端（SwiftUI）在 [`macos/`](macos/README.md)。** `src/` 中的 `remote-agent.cjs`、`task-worker.cjs`、`task-inspect.cjs` 等是运行在服务器上的程序，由两个客户端共用；其余为 Electron 版客户端，待原生版在 Mac 上验收后移除。

## 产品目标与需求

RemoteCC 的目标：**在本地以 Claude / Codex 客户端式聊天界面，通过 SSH 使用远端服务器已有的 Claude Code，尽量获得与本地使用一致的体验。**

主要场景是代码、运行环境和 Claude 都在服务器上，而用户在自己的电脑上管理项目、聊天、审批、上传文件和查看生成结果。主界面应是简洁的聊天工作台，不以终端窗口作为主要交互，不添加无关装饰或冗余的 AI 解释文案。

以下是目标需求与验收标准，**不是全部已实现的声明**。

| 范围 | 需求与验收标准 |
| --- | --- |
| SSH 连接 | 输入 SSH 别名或 `user@host` 即可连接；复用系统 SSH 配置、密钥、agent 和跳板机。连接状态明确，失败可重试；不要求用户为了聊天另行暴露公网 Web 端口。 |
| 项目与历史 | 连接后发现该远端用户可访问的 Claude 历史，以“服务器 + 项目目录”分组。先展示元数据，点开才加载正文，长对话分页；保留远端 session ID，可继续原会话。发现不完整或读取失败时明确提示，不能把部分结果当作全部历史。 |
| Claude 原生能力 | 尽可能复用远端 Claude Code 的命令、模型、技能、Agent、MCP、插件、配置和控制协议。能力列表来自远端，不维护一份假定完整的本地命令映射；新版本增加能力时应尽量自动发现。 |
| `/` 命令交互 | 输入 `/us` 即可提示 `/usage`；支持搜索、别名、方向键、Tab、Enter、Esc、中文输入及已有参数保留。`/model` 等命令应出现可操作的选择界面；有后续确认、表单、多步选择的命令应完整回传原请求，不能仅显示命令名或发送后无反应。 |
| 模型与设置 | 能读取远端模型并切换模型、思考强度及权限等设置。以远端确认作为成功依据，界面、当前会话和后续请求状态保持一致。支持远端账户实际使用的自定义模型 ID。 |
| 聊天与审批 | 流式显示回复、思考摘要、工具调用和执行结果；支持停止、排队、结构化提问、权限及计划审批。断线期间不自动代用户批准，重连后可继续处理待答请求。 |
| 远端文件 | 浏览项目目录、搜索和附加文件；支持上传、截图粘贴与拖放。上传成功后 Claude 必须能通过真实远端路径读取文件，同名文件和并发修改需妥善处理。 |
| 产物预览 | 服务器生成的文本、代码、图片、PDF 等可在客户端查看；无法直接预览的文件可以下载或以本地应用打开。展示完整远端路径，不能把远端路径误当本机路径。 |
| 持久会话 | SSH 断开、电脑休眠、客户端退出或崩溃，不应主动结束已开始的远端任务。重连恢复同一任务的输出和审批；不重复发送、不重复执行。进程死亡或服务器重启时明确报告状态，不能假装任务仍在运行。 |
| 网络与缓存 | 复用 SSH 长连接，具备 keepalive、退避重连和唤醒恢复；项目、历史、目录、能力和文件缓存有明确失效规则。按需加载、增量传输、取消过期请求，避免大文件操作阻塞聊天停止或审批。 |
| 日常项目操作 | 提供新建、续接、分支、重命名、归档、搜索及导出等会话操作，逐步补齐 Git 修改审阅、检查点、worktree 和后台任务管理。 |
| 验证与兼容 | 除单元测试外，必须验证真实 SSH、真实 Claude 与打包客户端。重点覆盖断线恢复、命令后续交互、模型实际切换、上传后读取及生成文件预览；不以模拟测试替代这些验收。 |

### 实现原则

- 优先使用 Claude 原生协议和能力，客户端负责呈现、传输与状态恢复。
- 学习并复用成熟开源客户端的适用实现，减少重复开发；保留上游许可和出处。
- AgentBox 是当前重点参考项目：学习其命令发现、补全、交互及会话处理，整合到 RemoteCC 的 SSH 架构中。目标是改进本项目，而不是要求用户改用 AgentBox 或迁移到 Docker 工作区。
- 按能力逐项实现和验证。原生终端专属功能、尚未支持的协议或表单必须明确标识，不能将“命令可见”当作“完整支持”。

### 当前状态与下一步

当前版本 **0.14.0** 已包含 SSH 复用与重连、服务器常驻 Node 代理（服务端不再依赖 Python）、实时文件树、多标签文件查看与编辑、Git 变更面板、内容搜索、按工具类型渲染的操作记录、按项目组织历史、常驻远端 SDK 会话、权限和 MCP 结构化提问，以及命令补全和模型/思考强度选择。

优先待完成：

2. 完善远端状态变化与界面同步，包括其他客户端追加历史、设置变化及会话重置。
3. 扩展持久会话恢复范围，包括跨客户端接管及远端进程异常后的状态核对。
4. 完善权限规则、计划审批、MCP/插件配置与后台任务管理。
5. 补齐文件多标签、编辑体验、Git 审阅、检查点和 worktree；持续以真实网络测试优化延迟、流量和恢复速度。

详细差距见 [FEATURE_PARITY.md](FEATURE_PARITY.md)；AgentBox 的具体学习范围、已整合项和边界见 [AGENTBOX_INTEGRATION.md](AGENTBOX_INTEGRATION.md)。

## 使用

打开 `dist/mac-arm64/RemoteCC.app`。

1. 点击左下角「连接 SSH」，或「设置」填写 `ssh axi`、SSH 别名或 `user@host`。端口可选，留空使用 SSH 配置。
2. 连接后在右侧文件树浏览服务器目录。单击目录展开，双击进入；服务器上的新增、修改和删除会实时显示，Claude 改动的文件和 Git 状态会标记在树上。右键可新建、重命名、删除、下载或附加文件。「变更」面板列出未提交的文件并显示差异，「搜索」面板搜索文件内容，⌘P 按名称打开文件。点击「设为工作目录」选择 Claude 的工作位置。已有消息的对话切换工作目录会创建新对话，避免串用上下文。
3. 在输入框发消息。Enter 发送、Shift+Enter 换行。回复支持 Markdown、代码复制、工具调用、权限确认和停止。

### 远端历史

连接 SSH 后自动列出该远端用户 Claude 配置目录下各项目的历史会话，可按名称、摘要、主机和项目路径搜索，点击「刷新历史」重新发现会话。

侧栏按「SSH 服务器 + 工作目录」分组，显示项目名及会话数。项目可以折叠，点击项目旁的「＋」在该目录新建对话；搜索时自动展开匹配结果。不同服务器或不同完整路径的同名项目保持独立。

列表只读取每个日志首尾各 64 KB 的元数据，不下载全部对话。点击会话才读取最近最多 50 条记录，较早记录按需加载；恢复使用原远端 session ID 和工作目录。图片原始数据和超长内容不随历史预览下载。选中日志时会在远端扫描消息索引；已加载的消息会缓存到本机，目前不自动同步其他客户端之后追加的消息。

### 会话与排队

“会话”面板可固定、归档或恢复当前对话。侧栏在“对话”和“已归档”间切换；归档不会删除远端文件。

回复时继续输入会加入队列，整轮完成后依次发送。队列可取消；停止、出错或应用重启后暂停，点击“继续队列”恢复。当前实现不是工具执行间隙插话。

### 上传与附件

拖入文件、粘贴截图或点击输入框的「＋」可上传到当前工作目录。输入 `@文件名` 搜索远端工作目录并附加。右侧「上传」将文件上传到正在浏览的目录。支持多选，单文件上限 1 GB，每批最多 20 个。传输显示进度，同名文件不会被覆盖。

上传成功后，文件作为附件出现在输入框中。发送时，客户端把文件的真实远端路径一起交给 Claude，供其通过 Read 等工具读取，包括图片。远端已有文件也可以在预览窗口中「附加到消息」。移除附件只取消附加，不删除远端文件。

### 缓存与传输

目录列表缓存 3 秒，同一目录并发读取合并；「刷新」跳过缓存，上传和保存后失效。文件预览每次检查远端版本（inode、大小、纳秒修改及变更时间），内容未变时复用本地缓存。图片/PDF 使用二进制传输，预览、下载和本地打开共用最多 256 MiB 的内容缓存；本地打开仍提供独立副本，避免外部编辑污染缓存。传输期间文件变化会拒绝保存本次下载。

持久任务在线时发送带版本号的状态增量，首次订阅及重连发送完整快照；不改变远端结果保存和审批规则。折叠项目仅创建分组节点，回复更新不重复重建未变化的侧栏和历史消息。

目录与预览切换会取消过期请求，每台服务器最多并发 4 个文件操作，保存和上传优先于排队的读取；聊天停止和审批使用独立通道。预览版本元数据跨重启保留，缓存清理合并执行并保护正在读取的内容。缓存上限在清理完成后生效，传输和正在使用的文件可能短暂超出上限。

远端历史在 Claude 配置目录下的 `remotecc-index/` 保存私有 JSON 索引，代理内存中保留最近使用的索引。列表分页使用一小时内有效的快照（保存在代理内存中，断线后需重新读取列表）；消息索引复用未变化的日志，追加时检查已有前缀的首尾并只读取新增完整行，截断或替换文件时重建。它是可重建缓存，不修改 Claude 原始历史。

相同服务器、项目和会话配置共享五分钟的远端命令/模型能力缓存；显式刷新或重新连接后重新读取。

### 查看远端生成的文件

点击文件树中的文件、工具卡片里的路径或回复中的文件链接，文件会在聊天旁的标签页打开。文件在服务器上变化时自动更新；有未保存编辑时不会覆盖，而是提示冲突。⌘W 关闭标签。

- 文本与源代码：最多预览前 1 MB；完整 UTF-8 文件可编辑并保存到远端，检测到版本变化时拒绝覆盖。关闭预览、窗口或退出应用时，未保存修改会提示确认。
- PNG、JPEG、GIF、WebP 与 PDF：内嵌预览，上限 20 MB。
- 其他类型：可下载。HTML 和 SVG 按文本显示，不执行远端脚本。
- 「下载」：选择本机保存位置。
- 「本地打开」：先下载副本到本机缓存，再用默认软件打开 PDF、图片、文本、Office 文档等支持的格式。本机需要安装对应软件。缓存副本的编辑不会自动传回服务器；需要自行另存后上传。

### SSH 与会话

复用本机 `~/.ssh/config`、密钥、SSH agent、跳板机配置及系统主机验证。使用系统 OpenSSH ControlMaster 建立独立连接，并复用同一连接传输聊天和文件。无需远端端口转发、Web 服务或 tmux。

目前支持非交互密钥/agent 认证；未加入密码输入、首次主机指纹确认和交互式 MFA 窗口。此类连接需先用系统 SSH 完成配置。不会关闭主机验证。服务器只需要 Node.js 18.14+ 及可找到的 `claude`（不需要 Python），使用远端已有的 Claude 配置；登录 shell 找不到 node 时会继续查找 nvm、fnm、volta 等常见位置。

连接时通过 SSH 安装按内容版本管理的单文件代理 `~/.local/share/remotecc/agent/<hash>/remote-agent.cjs`，并在一条 SSH 通道上常驻运行：文件、历史和任务控制请求共用这条通道，文件和任务状态变化由 inotify 主动推送，不再轮询，也不再为每个操作新开通道和解释器。上传和下载走独立通道，不会阻塞停止和审批。通道关闭时代理退出；已开始的 Claude 任务由独立进程持有，不受影响。首次发送时再安装 SDK 任务程序，不执行 npm install。

每条对话绑定独立的远端 Claude session ID，后续消息恢复同一上下文。首次发送后，由远端常驻进程持有同一个 SDK 会话，多轮消息使用持续输入流：断开 SSH、关闭客户端或客户端崩溃不会主动停止远端请求。重新打开同一本地资料并连接 SSH 后，恢复当前回复、工具状态和待审批问题。点击「停止」只中断当前回复，保留会话供下一轮继续；删除空闲对话时释放远端进程。离线时需先重连。

权限确认在远端等待，不因断线自动批准。尚未发出的本地队列在断开后暂停。任务 ID 在发送前落盘，启动重试沿用同一 ID，避免网络丢失确认后重复执行；远端通过版本化快照恢复显示，重复接收不重复追加消息。服务器重启、进程被杀或凭据失效不保证继续执行，恢复时会报告错误，不自动重跑任务。

辅助程序位于远端 `~/.local/share/remotecc/`，任务请求、结果和待审批状态位于 `~/.local/state/remotecc/tasks/`，目录权限为 0700，不开放监听端口。已确认落盘到客户端的完成结果保留至少 7 天，下次辅助程序检查时清理；未确认取回的结果与待审批任务不自动过期。当前恢复依赖原客户端本地任务记录，尚不支持另一台电脑接管任务。

SSH 每 15 秒检查本客户端的连接，失败后按约 1–30 秒退避重连；系统唤醒时立即检查。恢复后重新订阅原任务，不重新提交新任务。手动断开会取消重连。远端无响应由 SSH keepalive 检测，发现断线可能需要约 45 秒。

本机会话索引保存在用户数据目录的 `chats.json`，消息按会话保存在 `chats.json.sessions/`（文件权限 0600）。旧版记录首次保存时自动迁移，原文件保留为 `chats.json.legacy`。启动只读取会话元数据，点开后才读取本地消息；持续回复的 IPC 只发送变化的消息。普通流式更新合并写入，审批、完成、断开和退出时立即保存。不保存 SSH 密码或私钥。删除本地对话不会删除服务器上的 Claude 历史或文件。旧终端版的 `sessions.json` 不会被覆盖。

## 命令与设置

输入 `/` 查看命令，方向键选择、Tab 补全、Enter 执行。模型名称和权限按钮打开会话设置，读取服务器提供的模型列表，支持思考强度、快速模式、输出样式及额外目录。已有常驻会话通过原生控制通道应用设置，具体生效时机由 Claude 决定；启动参数变更需等待空闲后续接。新对话还可选择远端定义的 Agent；已有对话保留原 Agent。使用 Claude Code 原生系统提示，不在本地重写 Agent 指令。

`/` 菜单只展示当前远端 Claude Code 返回的命令及别名，描述和参数提示也来自远端。普通命令直接发送到远端。`/model` 和 `/effort` 会打开基于远端选项的选择界面，再通过 Claude 原生控制接口应用；带参数可直接切换，模型选择器也支持自定义模型 ID。`/clear` 对已确认的内置命令新建对话，保留旧历史与设置；同名项目技能仍交给远端执行。其他明确列出枚举参数的内置命令可先选择参数，再执行原命令。依赖终端交互的命令可能不能在当前协议下完整运行；出现远端反馈时直接展示；尚未支持的专用对话框不能视为完整适配。

客户端自己的上下文面板、分支、导出、Git 差异及 SSH 端口转发位于“会话”菜单。模型和权限仍可通过输入框下方按钮设置。“会话 → 刷新远端命令”可重新读取远端列表。

完整对标仍未完成，逐项状态和未实现功能见 [FEATURE_PARITY.md](FEATURE_PARITY.md)。

- `interaction-ui-smoke.cjs`：Electron 测试替身验证结构化表单的渲染与 IPC 提交、URL 拒绝和未知结构取消。
- `smoke.cjs`：使用 SDK/SSH 测试替身验证真实 Electron 页面和 IPC，不连接服务器。
- `files-smoke.cjs`：在 `axi` 的独立临时目录验证 SSH、上传、同名保护、预览和逐字节下载。
- `workspace-smoke.cjs`：使用真实 `axi` 和 Electron 页面验证文件工作流；仅原生文件选择/保存对话框、打开本地应用的动作由测试替代。
- `claude-workspace-smoke.cjs`：默认使用 `axi`，让真实 Claude 读取含随机校验码的上传文件、生成结果文件，验证预览/下载和第二轮上下文。仅允许对本次临时目录的 Read/Write/Edit 权限，测试结束清理临时目录。

上述 UI 脚本可用 `REMOTECC_EXECUTABLE` 指定打包应用的可执行文件。测试入口不打包进应用。

基于 Electron、Claude Agent SDK、marked、DOMPurify。渲染进程启用沙盒、上下文隔离和 CSP；Markdown 清理后显示。文件助手代码通过 SSH 单次运行；聊天任务由按需启动的远端进程托管。构建为本机未签名 Mac 应用。

远端 SDK 的 MCP 结构化提问共用表单组件：文本、数字、开关、单选、多选及浏览器授权链接。提交、拒绝、取消直接回复原请求；待答请求随远端任务保存，客户端关闭后重连可继续。暂不支持嵌套对象、正则等额外 schema 约束，会明确显示不支持并保留拒绝/取消操作。CLI 专用 `onUserDialog` 和所有终端菜单不在此支持范围。

权限弹窗可显示远端建议的规则及作用范围；勾选后由 Claude Code 原生保存。未勾选只允许本次操作。拒绝时可附带说明，提问多选可重复点击取消。
